== Description ==
A premium, MVC-based WordPress theme specifically designed for Senior Software Engineers. Features native multi-language support, GitHub integration, developer ranking system, and a high-performance Cyber-Brutalist aesthetic.

== Installation ==
1. Upload the theme folder to `/wp-content/themes/`.
2. Activate the theme via the WordPress Dashboard.
3. Go to 'DevPortfolio' menu to configure your GitHub token.
4. Use the Customizer for visual adjustments.

== Features ==
* MVC Architecture (OOP PHP 8.3)
* Native Multi-language (FA, EN, DE, AR)
* GitHub API Integration with Caching
* Developer Rank Calculator
* Daily Coding Challenge Shortcode
* Prism.js Code Highlighting
* Dark/Light Mode with LocalStorage
* Responsive Design with CSS Variables
