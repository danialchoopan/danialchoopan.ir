# Vibecode Studio - Premium Developer Portfolio Theme v2.1

Professional, high-performance WordPress theme for Senior Software Engineers.

## Core Features
- **MVC Architecture**: OOP structure in `src/` directory with custom Autoloader.
- **Native Multi-language**: FA, EN, DE, AR support with RTL/LTR switching.
- **Advanced Customizer**:
  - Typography: Select from Vazirmatn, Inter, Roboto, Sora.
  - Layout: Grid columns for portfolio (1-4).
  - Footer: Custom copyright text.
  - Toggles: Enable/Disable Preloader and Scroll Reveal animations.
- **GitHub Integration**: Caching repository data using Transients API.
- **Developer Rank & Daily Challenges**: Integrated technical widgets.
- **AJAX Contact System**: Non-reloading contact form with server-side validation.
- **Dark/Light Mode**: Full theme toggle with localStorage persistence.
- **Performance**: Built-in WebP hooks and lightweight core.

## Development
Compile Tailwind:
`npx tailwindcss -i ./assets/css/input.css -o ./assets/css/main.css --minify`
