**DevPortfolio Pro** is a high-performance, minimalist WordPress theme architected for Senior Software Engineers. It eliminates commercial bloat in favor of a pure, developer-centric experience built with utility-first CSS and a zero-external-dependency core.

## 💎 Architecture Principles

- **Zero External Bloat:** No FontAwesome, no Elementor, no external icon packages. All icons are handled via high-performance raw inline SVGs.
- **Utility-First Design:** Powered by Tailwind CSS for rapid, scalable, and maintainable styling.
- **Developer Aesthetic:** A premium Zinc-based dark-mode interface with high typographic hierarchy and clear engineering scannability.
- **Clean Core:** Strictly adheres to WordPress Theme Development Standards with proper escaping, hooks, and security.

## ✨ Key Features

- **Programmatic Seed Data:** Automatically populates 3 systems and 2 logs upon activation for an immediate out-of-the-box experience.
- **RTL & i18n Support:** Fully internationalized for English (LTR) and Persian (RTL) using the Vazirmatn font.
- **Premium Code Styling:** Technical blog posts feature IDE-like code blocks with modern typography.
- **Custom Portfolio CPT:** Dedicated architecture for engineering projects and technical spec mapping.

## 🛠️ Installation

1. **Upload via Dashboard:**
   - Compress the theme folder into a `.zip` file.
   - Go to **Appearance > Themes > Add New > Upload Theme**.
   - Choose the file and click **Install Now**.

2. **Clone directly:**
   ```bash
   cd wp-content/themes
   git clone https://github.com/danialchoopan/devportfolio-pro.git
   ```

3. **Activate:**
   - Upon activation, the theme automatically initializes the programmatic seed data.
